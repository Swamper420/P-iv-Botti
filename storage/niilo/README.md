# Niilo Reference Photos

Place clear reference photos of **Niilo** in this directory (`storage/niilo/`).

## Guidelines
- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`
- Recommended: **3–10 well-lit photos** showing Niilo's face clearly (front-facing and slight angles, with/without glasses or hats if applicable).
- Prefer photos where Niilo is the only (or largest/most prominent) face in the frame.
- Changes in this directory are picked up automatically — no bot restart required.
- Image files in this directory are ignored by `.gitignore` so personal photos are not committed to git.
